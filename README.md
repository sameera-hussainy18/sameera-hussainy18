## About Me

B.Tech Computer Science & Business Systems student at SASTRA Deemed University. I build end-to-end machine learning projects — from raw data to a trained, evaluated model — and I'm currently picking up the MERN stack to round out the web development side. Most of what I work on sits at the intersection of health/signal data and classification: brain MRI scans, cardiotocography readings, seismic waveforms.

## Projects

🧠 **[brain-tumor-cnn-classification](https://github.com/sameera-hussainy18/brain-tumor-cnn-classification)** — Custom CNN in PyTorch classifying brain tumor types from MRI scans, with training curves and a confusion matrix. *(team project with Surianandhan Sridhar)*
`Python` `PyTorch`

🩺 **[fetal-health-classification](https://github.com/sameera-hussainy18/fetal-health-classification)** — Fetal health status from cardiotocography data, comparing Logistic Regression, XGBoost, and an MLP. *(team project with Surianandhan Sridhar)*
`Python` `Scikit-learn` `XGBoost`

🌍 **[Applications-of-ML-in-earthquake](https://github.com/sameera-hussainy18/Applications-of-ML-in-earthquake)** — Seismic waveform pipeline combining CNN-based earthquake detection with XGBoost event classification.
`Python` `TensorFlow` `ObsPy`

💻 **[AIACP](https://github.com/sameera-hussainy18/AIACP)** — Computes a Hardware Health Score from CPU/battery/disk metrics and classifies devices into reuse tiers.
`Python`

📋 **[Placement_Tracker](https://github.com/sameera-hussainy18/Placement_Tracker)** — Full-stack placement-season tracker: applications, interview reminders, calendar view, session auth.
